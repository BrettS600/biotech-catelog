Link your eBay account

This lets your card collector read your own purchases and sales for the Revenue tab. It only reads. You sign in on eBay's own page; your password never comes here.

Step 1. Ask eBay for approval

Copy both values from your eBay developer account (Application Keysets, the Production row). They go straight to eBay; this page keeps and sends nothing.

eBay approved it.

Step 2. Hand the code to the collector
  1. Copy the code below.
  2. In the droplet's console run python3 /opt/pokemon-collector/repo/ebay_link.py
  3. Type your RuName when it asks, then paste the code.

The code works once and only for 5 minutes. If it runs out, reload this page without the code and approve again.
